# E-Dialect

E-Dialect 是一个面向方言、本地语言与民族语言数字化的开放 GitHub 工程社区。我们在这里共同建设可复用的软件、数据工具、研究基础设施与协作规范；参与者可以来自学校、社区、企业或个人项目。

## 重点计划：乡声万语

**一乡一声，万乡万语。**

乡声万语是 E-Dialect 社区内持续推进的一项长期产品、技术与地方语言数字化计划，不等同于整个 E-Dialect 社区。它目前包含两个边界清晰、可以独立部署的产品：

- **乡声集盒**：面向普通用户的本地语言工具、互动体验与可信众包入口。用户可以听、查、录、分享真实乡音，并看到贡献如何进入可追溯的资料链路。
- **万语校坊**：面向方言、本地语言与民族语言资料团队的智能协同校勘平台，支持成批材料、独立多人校对、差异发现、仲裁和可审计导出。

**兴化语记**品牌继续作为莆仙语旗舰 Distribution Profile / Language Space；它复用乡声集盒的通用底座，不是第三套后端。

乡声集盒与万语校坊保持独立部署、数据库与认证边界。近期协作采用可复核的 Review Bundle：显式导出、人工检查、导入、独立校对与仲裁，再经人工检查回流；不通过共享数据库制造隐式耦合。

## 社区、计划与公司的边界

- **E-Dialect** 是开放工程社区。
- **乡声万语** 是社区内的长期计划与产品体系。
- **北京塔聚科技有限责任公司**可承接部分商业合同、交付与付款事项，但不等同于 E-Dialect，也不等同于乡声万语。

代码、数据与成果的权利边界以各仓库 `LICENSE`、贡献者协议（CLA）、具体合同及适用的知识产权文件为准；社区身份或项目参与本身不自动转移权利。

## 开放协作

我们采用 AI-assisted / AI-native 协作，但要求证据与审查强度匹配风险。贡献者不需要为了行数而机械逐行复核所有低风险输出；必须如实写明 AI 用途、实际验证和未人工验证的部分，高风险变更还须经过针对关键路径的人工审查、回滚准备与对应负责人验收。

欢迎参与产品设计、前后端、数据治理、迁移、QA、资料校勘、语言学与研究工具建设。开始前请阅读组织的[贡献指南](../CONTRIBUTING.md)与[治理说明](../GOVERNANCE.md)。
