# E-Dialect

E-Dialect 是面向方言、地方语言、民族语言数字化与开放技术协作的 GitHub 社区。

我们共同建设可复用的软件、数据工具、研究基础设施与协作规范；参与者可以来自学校、地方社区、企业或个人项目。

## 当前重点：乡声万语

**一乡一声，万乡万语。**

乡声万语是 E-Dialect 当前重点推进的长期实践计划，希望让地方语言既能被真实使用，也能被可靠记录、整理与复用。它不等同于整个 E-Dialect 社区。

## 两个产品

### [乡声集盒](https://github.com/e-dialect/xiangsheng-box)

面向普通用户的地方语言工具与可信共建平台。可以查、听、说、分享家乡话，正常使用过程也会沉淀为可追溯的语言资料。

### [万语校坊](https://github.com/e-dialect/wanyu-proofreader)

面向资料整理团队的协同校勘平台。支持 PDF、CSV 等批量材料、多人独立校对、差异发现、仲裁和可审计导出。

兴化语记是莆仙方言的旗舰地方入口，逐步运行在乡声集盒的通用能力之上。产品架构、数据交换与身份边界由各仓库文档说明，不在组织首页展开。

## 如何参与

我们欢迎不同形式的贡献：

- **开发**：前后端、基础设施、开发工具与开放技术；
- **数据与资料**：材料整理、来源核对、数据质量与可追溯性；
- **QA 与用户测试**：真实旅程、可用性、跨端与发布验证；
- **方言与语言学**：正字、读音、IPA、语言背景与专业审核；
- **地方文化资源**：资料线索、授权协作与地方社群连接。

开始前请阅读组织的[贡献指南](../CONTRIBUTING.md)与[治理说明](../GOVERNANCE.md)，再进入对应仓库查看当前 Issue。GitHub 原生 Assignee 是正式 ownership 信号；具体项目负责人和执行节奏以相应仓库或 initiative 文档为准。

## 社区、计划与商业主体

- **E-Dialect** 是 GitHub 开放工程社区，不等同于公司法人，也不等同于乡声万语本身。
- **乡声万语** 是 E-Dialect 当前重点推进的长期 initiative。
- 目前乡声万语相关商业合作、签约与交付由**北京塔聚科技有限责任公司**作为商业/法律承载主体；具体权利义务以实际合同、许可证、CLA 和知识产权文件为准。

社区身份或项目参与本身不自动转移代码、数据或成果权利。

## 开放协作

我们采用 AI-assisted / AI-native 协作，但要求证据和人工审查强度与风险匹配。贡献者必须如实说明 AI 用途、实际验证和 `Not manually verified`；高风险变更还须经过针对关键路径的人工审查、回滚准备与对应负责人验收。
