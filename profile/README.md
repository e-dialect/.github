## 我们在做什么

很多地方语言并不缺资料：词典、录音、地方志、研究成果和使用者都真实存在。真正困难的是，怎样把这些分散的材料持续整理成**能查、能听、能录、能协作、能继续生长**的数字产品。

E-Dialect 是一个围绕地方语言数字化建设的开源社区。我们希望把一次次重复的采集、整理、校勘、数据建模和产品开发，沉淀成下一支团队也能复用的工具、规范和工程经验。

我们的基本想法很简单：

> **技术可以复用，语言判断应该留给真正懂这门语言的人。**

因此，我们既欢迎开发者，也欢迎语言学研究者、资料整理者、地方文化团队和普通方言使用者。会不会写代码，不决定你能不能参与。

## 现在正在做什么

目前社区的重点计划是 **乡声万语**。我们以莆仙方言的长期实践为起点，把已经走过的真实路径整理成可复用的方法和产品。

| 项目 | 现在解决什么问题 | 适合谁参与 |
|---|---|---|
| [乡声集盒](https://github.com/e-dialect/xiangsheng-box) | 面向普通用户的地方语言工具与共建平台：查、听、录、补充和分享家乡表达 | 前后端开发、产品设计、方言使用者、内容共建者 |
| [万语校坊](https://github.com/e-dialect/wanyu-proofreader) | 把 PDF、CSV、词典等资料交给多人协同校勘，形成可信结构化数据 | Web 开发、数据工程、资料整理、语言学研究 |
| [兴化语记](https://github.com/e-dialect/xiangsheng-box/blob/main/docs/HINGHWA.md) | 莆仙方言的长期实际应用，也是我们验证工具是否真的好用的地方 | 莆仙方言使用者、本地文化团队、内容贡献者 |

我们也维护一些更小的实验项目，例如语义检索、语音识别、IPA 语音合成等。它们可能还在快速变化，但欢迎感兴趣的人一起试、一起改、一起把它们做成熟。

## 第一次来，可以从这里开始

**如果你会写代码**  
看看 [乡声集盒](https://github.com/e-dialect/xiangsheng-box) 或 [万语校坊](https://github.com/e-dialect/wanyu-proofreader) 的 Issues。带有 good first issue / help wanted 的任务通常更适合第一次贡献。

**如果你不熟悉 Git / GitHub**  
可以先在 [Git / GitHub 协作练习场](https://github.com/e-dialect/code-contributing-practice) 完成一遍从 Fork、commit 到 Pull Request 的完整练习，再进入真实项目。

**如果你懂某一种方言或地方语言**  
你可以帮助核对读音、写法、释义、地域差异和资料来源，也可以直接提出“这个产品在真实使用中哪里不对”。很多最重要的问题，本来就不是代码问题。

**如果你有资料或正在做地方文化项目**  
欢迎先开 Issue 和我们聊聊资料结构、数字化流程和协作方式。即使暂时不适合直接导入，也可能帮助我们把工具做得更通用。

## 我们怎样协作

我们希望这里不仅“代码公开”，而且真的能让后来者接得上。

- **先解决真实问题。** 功能、模型和自动化都应服务于真实资料与真实用户。
- **保留来源和差异。** 方言经常没有唯一标准答案；不同地区、不同资料和不同人的说法都值得被正确记录。
- **AI 是助手，不是裁判。** AI 可以发现问题、生成候选、减少重复劳动，但重要语言判断需要材料与人的确认。
- **让贡献可以被复查和接手。** Issue、PR、测试、文档和数据来源都尽量留下清楚的上下文。
- **欢迎新人。** 如果一个任务只有原作者才能看懂，那首先应该改进的是项目本身。

更完整的协作方式见 [贡献指南](../CONTRIBUTING.md) 和 [社区治理](../GOVERNANCE.md)。

## 你可以贡献什么

贡献不只意味着“提交代码”。例如：

- 修复一个界面问题或补一个测试；
- 优化数据导入、校勘或搜索体验；
- 核对一组方言读音和释义；
- 整理公开资料的来源信息；
- 发现产品里不符合真实语言习惯的设计；
- 补充文档、教程、截图和部署经验；
- 提出一种新的地方语言试点方式；
- 帮另一个新人完成第一次 PR。

不知道从哪里开始也没关系。可以直接在相关仓库开一个 Issue，说明你会什么、对什么感兴趣，我们会尽量帮你找到合适的入口。

## 开源与许可

E-Dialect 的核心公共社区项目会持续保留公开的开源版本。各仓库采用的许可证、数据与素材使用规则可能不同，请以对应仓库中的 LICENSE、LICENSING.md 或资产说明为准。

乡声万语相关的商业合作与签约目前由 **北京塔聚科技有限责任公司** 承载；这不改变 E-Dialect 作为开放 GitHub 社区的协作方式。关于贡献者协议、数据与素材边界等更详细内容，可查看 [许可证政策](../LICENSING.md)、[资产与数据政策](../ASSET_AND_DATA_POLICY.md) 与 [开源承诺](../OPEN_SOURCE_COMMITMENT.md)。
