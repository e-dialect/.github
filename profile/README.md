# 乡声万语

**一乡一声，万乡万语。**

乡声万语是一套面向活态方言记录、使用、整理与长期保存的开放产品与技术体系。我们希望让方言不仅“被保护”，更能被真实地听见、使用、分享、校勘和沉淀。

## 核心产品

### 乡声集盒

面向普通用户的活态方言可信众包采集平台。

围绕“听 / 查 / 录 / 我”组织真实乡音：用户可以听真人录音、查词条、比较地区说法、留下自己的声音，并看到贡献如何进入可追溯的公共资料。

仓库：`e-dialect/xiangsheng-box`

### 万语校坊

面向资料整理团队的方言资料智能协同校勘平台。

支持 PDF/CSV 项目、多名校对员独立作业、差异发现、管理员仲裁和可审计导出。

仓库：`e-dialect/wanyu-proofreader`

### 兴化语记

莆仙方言旗舰地方站。

“兴化语记”品牌继续存在，长期技术底座并入乡声集盒；它也是乡声万语验证真实历史数据迁移、多方言产品化与地方运营的第一站。

## 共性技术

语音识别、方言模型、检索、标注辅助、数据转换与可审计 AI 能力尽量沉淀为共享技术服务或独立组件，供不同产品复用；产品本身保持清晰边界，不因为“复用”而强行共用一个数据库。

## 开放协作

我们采用 AI-assisted / AI-native 开发，但要求每位贡献者对需求理解、diff 审查、实际验证和最终结果承担责任。

欢迎参与方言数据、产品设计、前后端、迁移、QA、资料校勘与研究工具建设。
