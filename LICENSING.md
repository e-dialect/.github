# e-dialect Licensing Policy

This document describes the organization’s default licensing policy. It does
not replace the license files and path-level notices in an individual
repository.

## Original software

Original application, platform, and network-service code that e-dialect is
authorized to license normally uses the **GNU Affero General Public License
version 3 only (`AGPL-3.0-only`)**.

Every repository must state its own license. The absence of a root `LICENSE` or
an explicit path-level notice means that no open-source license should be
inferred from this policy or from another e-dialect repository.

AGPL permits commercial use subject to all of its terms. An organization that
cannot or does not wish to comply with the AGPL terms may contact the relevant
project maintainers about an alternative commercial license. A paid license is
not required merely because a use is commercial.

## Approved exceptions

An SDK, interoperability library, protocol schema, or developer-integration
component may use Apache-2.0 or MIT when its repository has made that choice
explicitly. Existing upstream-derived repositories may retain licenses such as
MPL or GPL. These exceptions are repository-specific and are not a basis for
silently relicensing other work.

## Third-party work

Forked, vendored, copied, generated, or modified upstream work retains its
original copyright and license notices. The e-dialect default does not replace
an upstream license. Contributors must identify third-party material and must
not remove its `LICENSE`, `NOTICE`, attribution, or copyright headers.

A Contributor License Agreement covers only rights the contributor actually
owns or is legally authorized to grant.

## Data and other assets

A software license does not automatically license datasets, corpora, dictionary
content, annotations, recordings, personal data, model weights, generated
artifacts, trademarks, names, or logos. Those materials require their own
express terms. The absence of such terms is not permission to reuse them.

## This repository

Unless a file states otherwise, the original community documentation in this
repository is licensed under the **Creative Commons Attribution 4.0
International Public License (`CC-BY-4.0`)**. See [`LICENSE`](./LICENSE).

# e-dialect 许可证政策

本文说明组织默认政策，但不替代每个仓库自己的许可证文件和路径级声明。

- e-dialect 有权授权的原创应用、平台和网络服务代码通常采用
  **GNU AGPL v3 only（`AGPL-3.0-only`）**。
- 每个仓库必须自行说明许可证；没有根 `LICENSE` 或明确的路径级声明时，不得从本政策
  或其他仓库推定已经获得开源许可。
- AGPL 允许商业使用，但使用者必须遵守其全部条款。无法或不希望遵守 AGPL 条款的
  组织可以联系对应项目维护者了解替代商业许可；商业使用本身并不强制购买许可证。
- SDK、互操作库、协议 schema 或开发者集成组件可以在仓库明确批准后采用 Apache-2.0
  或 MIT；上游衍生仓库可以保留 MPL、GPL 等原许可证。
- fork、vendor、复制、生成或修改自上游的作品继续适用原版权和许可证声明。组织默认
  政策不能覆盖第三方许可证，CLA 也只覆盖贡献者实际拥有或有权授予的权利。
- 软件许可证不自动授权数据集、语料、词典内容、标注、录音、个人数据、模型权重、
  生成物、商标、名称和 Logo；没有单独条款不等于允许复用。
- 本仓库中原创社区文档除另有说明外采用 **CC BY 4.0**，详见 [`LICENSE`](./LICENSE)。
